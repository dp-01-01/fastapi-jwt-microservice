\# FastAPI JWT Authentication Microservice



A FastAPI-based microservice implementing user registration, JWT authentication, password hashing, and protected user management APIs.



\## Features



\- User registration

\- Secure password hashing using bcrypt

\- JWT-based authentication

\- Protected user profile endpoint

\- Update user details

\- Delete user account

\- SQLite database

\- Automatic API documentation with Swagger UI

\- Pydantic request and response validation



\## Technologies Used



\- Python

\- FastAPI

\- Uvicorn

\- SQLite

\- Pydantic

\- PyJWT

\- bcrypt
